**Project Title:** Todo List Dashboard

 **What It Does**

* Fetches initial tasks from a public API (`jsonplaceholder.typicode.com`)
* Lets users:
  * Add new tasks (by pressing **Enter**)
  * Mark tasks as **completed**
  * **Delete** selected tasks (with checkboxes)
  * **Clear** all tasks from both screen and `localStorage`
* Automatically saves all user-added tasks to `localStorage` so they persist after refresh
* Responsive layout with clean design and custom buttons

**Tech Used**

* **HTML5** – Markup structure
* **CSS3** – Styling and layout (media queries for responsiveness)
* **JavaScript (ES6+)** – Interactivity and logic
* **Axios** – For fetching data from the API
* **LocalStorage** – To persist tasks between sessions
